# CLAUDE.md Builder

## Khi nào dùng
- Khi cần tạo mới hoặc cập nhật `CLAUDE.md` cho project.

## Tài liệu bắt buộc đọc
- `docs/CODEX_CLAUDE_MD_CONCEPT.md`
- `CLAUDE.md` (nếu đang update)

## Quy trình khuyến nghị
1) Xác định loại project, tech stack, status, deploy.
2) Quét cấu trúc folder và các quy ước hiện có.
3) Ghi rõ các ràng buộc (bảo mật, GDPR, auth, i18n).
4) Liệt kê commands quan trọng và key files.
5) Giữ nội dung ngắn gọn, không lặp lại docs chi tiết.

## Checklist nhanh
- [ ] Có Overview + Tech Stack
- [ ] Có Key Directories + Conventions
- [ ] Có Commands + Environment
- [ ] Có Do/Don’t + Key Files
- [ ] Không chứa secrets
